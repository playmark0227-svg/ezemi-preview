## A. 申込・決済
| | 内容 | 状況 | どこ |
|---|---|---|---|
| A-1 | LP→申込→決済→即時に会員アカウント発行・案内メール自動送信 | ◎ | `site.js checkout()` / `domain.js signup()` |
| A-2 | 入会金（初回のみ）+ 月額サブスクを1フロー。カード必須 | ◎ | 同上 |
| A-3 | 初月無料。クーポン/オファー別の出し分け（モニター＝入会金免除＋初月無料） | ◎ | `coupons` / 管理画面「料金・クーポン」 |
| A-4 | 自己解約が会員だけで完結。解約後も期間末まで閲覧可、以降自動遮断 | ◎ | 会員ページ「アカウント」/ `cancelSelf()` |
| A-5 | 支払い失敗時：自動リトライ＋本人へ自動通知＋一定期間で自動的に閲覧停止 | ◎ | `refresh()` の past_due 処理 |
| A-6 | 会員資格と閲覧権限の完全自動連動 | ◎ | `statusOf()` / `canView()` を全画面が参照 |

※ 実際のカード決済は Stripe 接続後に◎になります。試作版は決済の成功/失敗を再現できるモックです（管理画面の会員個別画面から「次回の決済を失敗させる」で確認できます）。
