発注仕様書 v1（株式会社知上会 / 2026年7月）を、そのまま動く形にしたものです。
**2026-08-12 の打ち合わせで「送っていただけたら一回バーッと作ります」と話したぶんの現物** にあたります。

## 開くには

**プレビュー： <https://playmark0227-svg.github.io/ezemi-preview/>**
（検索避け済み・URLを知っている人だけが見られます）

手元では `index.html` をダブルクリックすれば動きます（サーバー不要・依存ライブラリなし）。
うまく動かないときは、このフォルダで下を実行して <http://localhost:8765> を開いてください。

```bash
python3 -m http.server 8765
```

| ページ | ファイル | 入りかた |
|---|---|---|
| 公開サイト（HP内に置く想定） | `index.html` | そのまま |
| 会員ページ | `member.html` | デモ用ボタンで即ログイン／パスワードは `demo1234` |
| 管理画面（代表が触るところ） | `admin.html` | パスワード `ezemi` |

初回に開くとデモの会員6名・配信10本が入ります。**管理画面 → データ → 「デモデータを消す」で一括削除**できます。

### 右下の「検証用」バー

日付を +1日 / +1週 / +1ヶ月 と進められます。ここが本番との違いを見てもらう一番早い方法です。
たとえば **+1ヶ月** を押すと、誰も操作していないのに次のことが全部起きます。

- 全員の月額が自動で決済される（入会日を基準に毎月同日）
- カードが通らない会員は自動リトライ → 猶予を過ぎたら自動で閲覧停止
- 解約した会員は期間末で自動的に終了し、会員ページが閉じる
- 1ヶ月を過ぎた配信が自動で非公開になり、「殿堂入り」だけが残る
- 予約投稿がその時刻に自動で公開され、メールとLINEの通知が飛ぶ

**本番ではこの日付操作バーは外します。**

## 直したものを公開に反映するには

GitHub Pages は CSS と JS を10分キャッシュします。直したまま push すると、
先方の画面で古いファイルと新しいファイルが混ざることがあります。**必ず先に版番号を上げてください。**

```bash
./bump.sh && git add -A && git commit -m "修正内容" && git push
```

`bump.sh` は3つのHTMLの `?v=...` を書き換えるだけです。反映まで1〜2分かかります。

## 本番にするときに差し替えるところ

想定は **Firebase Hosting + Firestore + Authentication + Cloud Functions ＋ Stripe** です
（打ち合わせで話した「Googleのサーバー・従量課金」がこれにあたります）。

| いまの実装 | 本番 |
|---|---|
| `store.js`（localStorage） | Firestore。読み書きの入口はこの1ファイルに閉じています |
| ログイン（`member.js` のメール＋平文パスワード照合） | Firebase Authentication |
| 決済モーダル（`site.js` の `checkout()`） | Stripe Checkout（入会金＝一回払い＋月額＝サブスクを1フロー） |
| `domain.js` の `refresh()` が回している自動処理 | Stripe の Webhook ＋ Cloud Scheduler で定期実行 |
| `notifyMember()` の送信ログ | 会社ドメインからのメール送信（SPF/DKIM）＋ LINE Messaging API |
| 動画URL欄 | YouTube 限定公開などの埋め込み（URL直打ちで外から見えないもの） |

`refresh()` は「いま何時か」を渡すだけで全部の状態を計算し直す作りにしてあります。
サーバー側に移すときも、この関数をそのまま定期実行に載せられます。

### 引き継ぎについて（仕様書 0-3 / 非機能要件）
- 利用サービス（Firebase・Stripe・LINE）のアカウントは**すべて知上会名義**で作ります。制作者アカウント内に御社データは置きません。
- コードはこのフォルダ一式で完結しています。特殊なビルドツールを使っていないので、第三者がそのまま引き継げます。
- 会員情報・提出物は管理画面から CSV と JSON で書き出せます。
