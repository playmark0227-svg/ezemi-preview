# 画像素材について

すべて **株式会社知上会 コーポレートサイト（`playmark0227-svg/chijokai-site`）と共通** のものです。
同じ運営会社なので、ロゴ・写真・アイコンをそのまま流用しています。
差し替えるときは、あちらの `assets/img/` と揃えてください。

| ファイル | 出どころ | 掲載箇所 |
|---|---|---|
| `logo-full.png` / `.webp` | 先方提供の正式ロゴ（横組み） | 全ページのヘッダー・フッター。濃色の面では CSS で白抜き |
| `logo-mark.png` | 先方提供のシンボルマーク | favicon の生成元 |
| `favicon.png` / `apple-touch-icon.png` | `logo-mark.png` から生成 | ブラウザのタブ・ホーム画面 |
| `sea-light.jpg` / `.webp` | 先方提供の実写（海中から見た光） | トップの表紙 |
| `study-desk.jpg` / `.webp` | Unsplash（商用可・クレジット表記不要） | 「7回で身につくこと」の背景 ※仮素材 |

`study-desk` だけが仮素材です。実物の写真をいただければ差し替えます。
